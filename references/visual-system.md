# 视觉系统与蓝图

## 目的

蓝图用于锁定页面的构图、信息层级、密度和视觉语言。蓝图可来自用户、设计师、Image2 或 ImageGen，不受固定风格数量限制。

## 风格优先级

1. 用户明确指定的品牌规范、颜色、参考图和设计稿。
2. 用户已确认的蓝图。
3. 根据内容新生成的任意风格。
4. `assets/palette-samples/` 的 8 种参考样张。

8 种样张只是用户没有方向时的参考，不得宣称只能从 8 种中选择。用户指定“冷白灰 + 深紫”等方向时，直接围绕该方向生成代表页。

## 风格确认

在批量生成蓝图前确认：

- 画布比例与留白；
- 背景、主色、强调色和状态色；
- 标题、正文、数字、注释的字体层级；
- 面板、边框、分隔线、阴影和圆角语言；
- 图表风格与图标风格族；
- 页眉、页脚、来源和 SO WHAT 的固定位置；
- 页面信息密度。

先做一张能代表整套 deck 的完整样页。用户确认后，将上述内容写入 `visual_master`，再批量生成剩余全部蓝图。代表页确认只锁定视觉方向，不代表整套蓝图已经确认。

## 逐页蓝图

每页必须体现：

- 结论型标题；
- 主要论证或主图；
- 支撑证据、案例、表格或解释层；
- SO WHAT 或明确结论；
- 与大纲一致的信息区和阅读顺序。

蓝图不能删掉已确认内容，也不能为了方便还原而退化成占位框。蓝图文字可能有错，最终真实内容必须来自 `slide_content_lock`。

## 整套蓝图确认门

代表蓝图确认后，按已锁定的 `visual_master` 完成全部目标页面蓝图，再集中交付用户审阅。默认交付：

- 每页独立高清蓝图；
- 按页码排序的整套缩略图总览；
- 页码、标题和蓝图文件清单。

在用户明确确认整套蓝图前：

- 不进入可编辑 PPT 制作；
- 不并行启动阶段 3；
- 不把代表页风格确认视为其他页面构图确认。

用户只要求修改个别页面时，只重新生成受影响页面。全部页面通过后记录 `blueprint_set_confirmed: true`。

单页任务中，代表蓝图就是整套蓝图。用户直接提供完整蓝图时，先确认这些蓝图是否覆盖全部目标页面；缺页时先补齐，覆盖完整时可直接进入整套蓝图确认。

## 用户直接提供蓝图

跳过风格探索，只提取：

- `canvas`：宽高比、背景；
- `grid`：边距、列、间距、对齐线；
- `typography`：标题、正文、数字、注释；
- `surfaces`：面板、卡片、表格、图表区；
- `chrome`：页眉、页脚、页码、来源；
- `visual_language`：图表、图标、连接线和装饰；
- `reusable_components`：跨页复用组件。

随后建立精简 `visual_master`，并复述将按该蓝图作为阶段 3 基准。用户已明确要求“按此还原”时，无需再次要求选择固定风格。

## 质量档位的蓝图测量

### fast

- 制作前识别并估算 P0 的位置和比例：标题、关键数字、主图/主流程、SO WHAT、品牌标识。
- 制作前估算 P1 的容器、组件组和阅读顺序：卡片组、表格、面板、次级图表。
- P2 只记录风格与大致区域。
- 不建立坐标 registry，不做生成后的 P0/P1 对照测量；这些属于 standard/B 或 precision。

### standard

- P0/P1 逐项或组内锚点测量。
- 对关键图表、架构、时间线做局部对照。

### precision

- 所有可见元素进入 registry。
- 核心曲线、UI、品牌图形和用户点名区域进入路径/像素级检查。
- 只有该档位才要求完整局部裁切和差异图。

## 图标

蓝图只定义图标的语义、风格和大致位置。普通图标不要求一模一样；阶段 3 可用同风格语义近似图标。Logo、品牌图形和核心业务符号除外。

## 蓝图确认输出

代表蓝图确认时简短列出：

- 选定/指定的风格；
- 代表页；
- `visual_master` 摘要；
- 剩余蓝图生成计划。

整套蓝图确认时列出：

- 总页数与页码顺序；
- 每页标题与蓝图文件；
- 已修改页面；
- `blueprint_set_confirmed` 状态；
- 下一步将进入阶段 3 的 A 版样板页，而不是直接批量生成完整 PPT。
